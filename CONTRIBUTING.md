# Contributing

Independent criticism, counterexamples, and references to existing literature are welcome. For each claim, distinguish: the precise mathematical statement, theorem hypotheses, computations, numerical evidence, and conjecture. Include deterministic reproducers where possible.

Do not describe a result as Lean-verified without an actual checked Lean proof, or as new without checking prior literature. Please open an issue for any suspected mathematical error, with the smallest failing step and expected correction.
