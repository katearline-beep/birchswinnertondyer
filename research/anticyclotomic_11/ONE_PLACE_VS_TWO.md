# The two-prime logarithm kernel is not the one-prime modified Selmer group

**Important scope clarification (2026-10-17).** This note refers to C-0002's finite coefficient module and its local logarithms, *not* a computation of the global modified Selmer group.

Agboola–Castella (2021), §1 (author manuscript p.2) define the modified Selmer group using the kernel of localization at one chosen prime `𝔭` over p, rather than a simultaneous condition at both primes above p. Under the relevant finiteness hypotheses, its rank is r−1, not r−2. This is precisely why our previously computed two-local-place kernel is not the Selmer group used in their regulator.

On the free coefficient module with ordered basis `(P1,P2,P3,P4,H)`, our C-0002 local log matrix modulo 14641 is

```
lambda+ : 7462  14432   1427   7989   1495
lambda- : 7462  14432   1427   7989   7921
```

The first coefficient 7462 is a unit modulo 11. The kernels of the *single-place* maps on this module are free of rank four:

```
K+ = span{ P2−8690 P1, P3−14082 P1, P4−12835 P1, H−1097 P1 }
K- = span{ P2−8690 P1, P3−14082 P1, P4−12835 P1, H−11179 P1 }
```

The difference between the two H-coefficients is `10082 mod 14641`, a **unit** modulo 11. Thus their intersection is generated by the **three** rational combinations `P2−8690P1`, `P3−14082P1`, `P4−12835P1`. These are finite-precision *coefficient vectors*, not torsion identities in E(K).

The one-place kernel being rank four corresponds formally to the *size* expected for the modified Selmer group when r=5, but **is not proof** that this finite coefficient submodule is the global Selmer group: one must still handle the global Selmer definitions, the localization maps and `Sha[11∞]` assumptions.

This note corrects any earlier suggestion that the rank-three two-place local-log kernel could simply *be* the modified Selmer group or the first derived-height radical. Those are three different objects.

**References:** [Agboola–Castella, J. Théor. Nombres Bordeaux 33 (2021), §1 and §4](https://www.numdam.org/articles/10.5802/jtnb.1174/); [our C-0002 local-log certificate](../split11/KERNEL.md).
